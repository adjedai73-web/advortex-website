Un seul fichier `index.html` + dossier `assets/` — 100 % statique, aucune dépendance serveur.

- Services : gestion réseaux sociaux, production vidéo, stratégie, publicité Meta

- Méthode en 4 étapes

- FAQ + formulaire de contact qui ouvre WhatsApp avec message pré-rempli
